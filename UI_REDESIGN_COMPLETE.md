## 🎨 Design System

### Color Palette:
```css
Background: linear-gradient(135deg, #0a0e27, #1a1a2e, #16213e)
Primary Accent: #00d4ff (Cyan)
Secondary Accent: #7b2ff7 (Purple)
Text Primary: #e8e8e8
Text Secondary: #b8b8b8
Glass Background: rgba(255, 255, 255, 0.05)
Border: rgba(0, 212, 255, 0.2)
```

### Typography:
- Font Family: Inter, -apple-system, system-ui
- Body Text: 15px, line-height 1.7
- Headers: Cyan color (#00d4ff)
- Code: Fira Code, Courier New

### Effects:
- **Glassmorphism**: backdrop-filter: blur(10-20px)
- **Glow**: box-shadow with cyan/purple
- **Gradients**: 135deg angle
- **Animations**: 0.3-0.4s ease
