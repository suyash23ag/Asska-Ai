def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```

## 🎓 For Coding Mentor

Works perfectly with AI Coding Mentor responses:

**Example:**
```
📘 Concept:
Binary search divides the array in half each time.

⚡ Approach:
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

🧠 Complexity:
Time: O(log n)
Space: O(1)
```
